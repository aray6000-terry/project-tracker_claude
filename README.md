# 弱電專案進度追蹤

依《專案工程師養成計畫》的 8 個施工時間結點，追蹤弱電監控專案的完成事項、查驗關卡與產出表單。單一 HTML 檔，不需安裝、不需伺服器。

## 使用方式

1. 開啟 GitHub Pages 網址（設定方式見下方），或直接用瀏覽器開啟 `index.html`。
2. 按「新增專案」，輸入專案名稱、業主、負責工程師、帶案師父與預計驗屋交屋日。
3. 填入交屋日後，系統會依常見工序帶入今天以後各結點的建議日期；已過去的結點請自行填寫，所有日期都可修改。
4. 在專案頁逐項勾選「完成事項」「查驗關卡」「產出表單」，結點全部勾完會自動記錄完成日。
5. 預計日期已過但未完成的結點會標示為「逾期」，列表頁可篩選「有逾期」的專案。

## 8 個時間結點

| # | 結點 | 必過關卡 |
| --- | --- | --- |
| 1 | 簽約成交 | 送審核可後才請購；長交期設備另抓交期 |
| 2 | 開工前 | 開工會議確認介面分工與配管圖 |
| 3 | 上樑前 | 封板、灌漿前拍照查驗配管 |
| 4 | 上樑～消防檢查 | 穿線後測線，兩端標示 |
| 5 | 消防檢查～使照申請 | 與消防廠商實測消防連動 |
| 6 | 櫃台機櫃完工～驗屋 | 單機、系統、整合三階段測試 |
| 7 | 驗屋交屋 | 驗收單簽認，確認保固起算日 |
| 8 | 交屋後 | 缺失結案、尾款請款、首次保養 |

## 資料儲存與共用

- 資料存在**各自瀏覽器**中（localStorage），不會上傳到 GitHub 或任何伺服器。
- 換電腦、與主管或同事共用時：按「匯出資料」存成 JSON 檔，對方按「匯入資料」選擇取代或合併。
- 建議每週匯出一次備份，存到公司雲端資料夾。
- 清除瀏覽器資料或使用無痕視窗時，資料會消失，請先匯出。

## 開啟 GitHub Pages

1. 進入本儲存庫 → **Settings** → **Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save。
3. 約 1–2 分鐘後即可用 `https://<帳號>.github.io/project-tracker_claude/` 開啟。

## 修改結點內容

結點名稱與勾選項目定義在 `index.html` 的 `NODES` 陣列；建議日期的推算天數在 `OFFSETS` 陣列（以交屋日為 0，負數為交屋前天數）。修改後請注意：已建立的專案會沿用新的項目文字，但勾選狀態依項目順序對應。
